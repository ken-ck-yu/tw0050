## Decisions I had to make
1. **Manifest path for the `qa` area.** `paths.manifest_file` has no area argument, so raw and qa would share one manifest. I write the qa manifest as dataset `qa/<dataset>` (`data/state/manifest/<source>/qa/<dataset>.jsonl`). A raw dataset literally named `qa` would collide.
2. **`QuotaLimiter.update(limit, user_count)`.** Sets the instance limit (not persisted). If the server's `user_count` exceeds the stamps in our window, the difference is added as stamps at "now" (conservative: they expire an hour later). Cap is `floor(limit * fraction)`, so 510 for 600 at 0.85.
3. **`QuotaLimiter.slot()`** records the request when the slot is granted (at start, not completion) and does not hold the lock during the request. It is still a context manager so callers use it like `HostLimiter`.
4. **`HostLimiter`** writes the completion time in a `finally`, so a failed request still spaces the next one.
5. **`get`** does not filter on status (only `ok` responses are put); ties on `fetched_at` go to the later write. A per-instance index of (request_key to latest fetched_at, shard) is refreshed incrementally from the manifest on each `get`, so other processes' shards are seen.
6. **Flush failure** keeps the buffer for a retry. If the manifest append fails after the shard rename, the shard is deleted. A crash between rename and manifest append leaves an unlisted shard, which `verify` reports.
7. **`put_quarantine`** writes a single-row Parquet with the same schema, named `quarantine-<UTC stamp>-<uuid8>.parquet`, returns the path. Naive `fetched_at` raises `ValueError`.
8. **`verify` returns `Problem(kind, file, detail)`** with kinds `missing`, `sha256_mismatch`, `unlisted`, `bad_manifest_line` (spec leaves `Problem` undefined).
9. **Buffers are per (source, dataset)**, so the 25-response limit applies per dataset, and `flush()` flushes all datasets. Temporary files are named `.tmp-<shard>` (never match `shard-*.parquet`).

- **What in my instructions was missing, ambiguous or wrong:** `Problem` type undefined; the manifest path ignoring area (decision 1); whether the shard limit is per dataset or global; what `update` does with `user_count`; whether `QuotaLimiter.slot()` is a context manager (the spec only says it sleeps). The spec's `put` parameter named `request_key` shadows the module function of the same name (needed a noqa).
- **What I would do differently next time:** ask the Lead for the manifest-area signature before building on it.
