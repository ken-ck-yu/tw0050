## What to build
**`build_books(data: DevData, start: date, end: date) -> list[TargetBook]`** implementing the card exactly:
1.  Decision dates: for each calendar month `M` whose 10th falls in `[start, end]`, the decision date is the first trading day on or after the 10th of `M` (from `data.calendar`). Execution is the evaluator's job (next trading day open).
2.  At each decision date use only `data.as_of(decision_date)` (never `data.tables` directly, never `adjusted_prices`, which `as_of` refuses). The visible tables are `monthly_revenue` (rows are the clean rows: `stock_id`, `event_date` = first day of the revenue month, `revenue`), `universe_membership`, `prices_raw`.
3.  Universe: the rows of `universe_membership` for the latest `month_end` visible; exclude `is_benchmark` rows; watchlist rows are allowed.
4.  Signal: for the revenue month `m` just published (the month before the decision month) and each universe stock, `yoy = revenue(m) / revenue(m - 12 months) - 1`, requiring both months visible and the year-ago revenue greater than zero. Stocks failing the requirement are not eligible.
5.  Score = `yoy`. Eligible count `n`. Choose the top `k = ceil(0.10 * n)` stocks by `yoy` (ties by higher `yoy` first, then lower `stock_id`); if `n == 0` the book is empty (all cash). Weight each selected name `min(1/k, 0.10)`. The rest is cash.
6.  Return a list of `TargetBook(decision_date, weights)` in date order.

**`diagnostics(data, books) -> dict`**: for each pair of consecutive books, the gross open-to-open return (adjusted, `data.adj_open`) of the selected names and of the median universe stock from the first book's execution open to the next book's execution open; report `top_vs_median_gross_monthly` (mean over months of top-decile mean minus universe median), the number of months and the average number of names. Used for the card's third falsification test.

**`run_h1(settings, window: str) -> dict`**: `window` is `"train"` or `"validation"`. Loads dev data with `load_dev_data` for that window (history before the window start for year-ago revenue is available because the loader keeps `monthly_revenue` back to the start of data), builds books, calls `run_backtest(data, books, card_id="H1", params={"top_fraction": 0.10, "max_weight": 0.10}, window=window)` exactly once, runs `diagnostics`, evaluates the card's falsification rule on the validation window (net Sharpe below 0.5, or net mean excess return over 0050 not above zero, or top-decile gross monthly return not above the universe median) and returns a dict. Also write `research/runs/H1_<window>.json` (record fields from the evaluator's `RunRecord` plus the diagnostics and the falsification verdict; no daily series) and `research/runs/H1_<window>.md` (a one-page table: window, net Sharpe, 0050 Sharpe, net annual return, excess return, annual turnover (one-way), cost drag, max drawdown, attempts this cycle, deflated Sharpe, falsification verdict, and the three conditions). A validation-window verdict of "falsified" is printed as such with no softening.
