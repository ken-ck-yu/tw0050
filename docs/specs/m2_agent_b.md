# Agent B spec (M2, seed data): corporate actions, price limits, adjusted prices, benchmark

Builds on `docs/specs/m0_specs.md` (sections 2, 5, 7, 8, 15 apply). One builder, own git worktree. Owns only: `src/twdata/ingest/{corporate_actions,price_limits,adjusted,benchmark}.py`, `tests/agent_b/**`, `tests/fixtures/agent_b/**`, `docs/data_dictionary/b_corporate_actions.md`, `audit/runs/2026-11-14_agent_b_1.md` (include what in the instructions was missing, ambiguous or wrong). No network access: tests use `tests/fixtures/lead/` and a fake transport. Same conventions as Agent A's spec (the `RunContext`, `Response.records`, `fetched_at`, `state`, `DATASETS`). Dates in responses are ROC dates (`roc_to_date`), TWT49U also uses the form `104年06月01日`.

**`corporate_actions.py`** (`DATASETS = {"corporate_actions": run}`): sources for `[start, end]` (call each endpoint in windows of one calendar year, except TWSE `twt49u` which takes the full span): TWSE `twt49u` (fixture `twse/twt49u_2025_trimmed.json`), TWSE `twtauu` (`twse/twtauu_2015_2022_trimmed.json`), TPEx `ex_daily` (`tpex/ex_daily_2016_trimmed.json`), TPEx `revivt` (`tpex/revivt_2015_trimmed.json`), and the manual file `config/manual_corporate_actions.yaml`. Read the field lists from the fixtures.
*   `twt49u`: `資料日期` → `event_date` (the ex-date); `股票代號` → `stock_id`; `除權息前收盤價` → `prev_close`; `除權息參考價` → `reference_price`; `權/息` is `權` → `action_type = ex_rights`, `息` → `ex_dividend`, `權息` → `ex_rights`; fill `cash_dividend` and `stock_dividend_per_1000` where the feed gives them, else null. `market = "TWSE"`. The feed lists ETFs (for example 0050) and stocks.
*   `twtauu`: `恢復買賣日期` → `event_date`; `股票代號` → `stock_id`; `停止買賣前收盤價格` → `halt_close` and `prev_close`; `恢復買賣參考價` → `reference_price`; `減資原因` → `reduction_reason`; `action_type = capital_reduction`; `market = "TWSE"`.
*   `ex_daily`: `除權息日期` → `event_date`; `代號` → `stock_id`; `除權息前收盤價` → `prev_close`; `除權息參考價` → `reference_price`; `權/息` as above; `現金股利` → `cash_dividend`; `每仟股無償配股` → `stock_dividend_per_1000`; `market = "TPEx"`.
*   `revivt`: `最後交易日之收盤價格` → `halt_close` and `prev_close`; `減資恢復買賣開始日參考價格` → `reference_price`; `減資原因` → `reduction_reason`; the resumption date field → `event_date` (7-digit ROC or `YYYYMMDD`, confirm from the fixture); `action_type = capital_reduction`; `market = "TPEx"`.
*   Manual file: one row per entry with `action_type`, `event_date`, `halt_close` (also `prev_close`), `reference_price`, `ratio`, `market`, `stock_id`. A null `reference_price` is written null and the adjustment factor falls back to `1/ratio`.
*   All rows: `available_at = avail_next_day_0830(event_date, ctx.calendar)`; `fetched_at` = the response's `fetched_at` (manual rows use the file's modification time in UTC). The key is `market, stock_id, event_date, action_type`; if a feed gives two rows with one key (for example an ex-rights and a cash dividend on one day), keep the one with the larger `stock_dividend_per_1000` and note the collision count in the run report.

**`adjusted.py`**: a function `adjusted_series(con, as_of=None, stock_ids=None)` returning a pyarrow table `(market, stock_id, event_date, close, factor, adjusted_close, is_ex_date_window)`. Factor of one event is `reference_price / prev_close` for `ex_dividend`, `ex_rights`, `capital_reduction` and `split`/`par_value_change` rows (a null `reference_price` uses `1 / ratio`); `adjusted_close(t) = close(t) * product of factors of events with event_date > t` and, when `as_of` is given, `available_at <= as_of`. Two events on one date multiply. `is_ex_date_window` is true on dates `d` where an event has `event_date == d` and (when `as_of` is given) `available_at > as_of`. Reads `default_prices_raw` and `default_corporate_actions` through DuckDB views. Also register the view `adjusted_close` for `as_of` = infinity (full adjustment, labelled "validation and labels only, not a feature input") with `register_view`.

**`price_limits.py`** (`DATASETS = {"price_limits": run}`): TWSE from `twt84u(d)` (fixture `twse/twt84u_20200615.json`; the row dated `d` gives the limits for `d`; the field `開盤競價基準` appears twice, use the unique-name rule `開盤競價基準#2`); fields `漲停價` → `limit_up`, `跌停價` → `limit_down`. TPEx from the raw `otc` file of the previous trading day (`次日漲停價`, `次日跌停價` stored on the next trading day; the sentinel `9999.95` / `0.01` becomes null). `available_at = avail_same_day_1800(event_date)`. Read the TPEx raw responses through `ctx.cache` (cache-first fetch of `tpex.otc` with `store=True`), not by network.

**`benchmark.py`** (`DATASETS = {"benchmark_index": run}`): `ctx.twse.mi_index_tr(d)` (the index table of the `MI_INDEX` fixture `twse/mi_index_20160601.json`): row `發行量加權股價報酬指數` → `index_id = "TAIEX_TR"`, row `臺灣50報酬指數` → `"TAIWAN50_TR"`, `value = parse_number(收盤指數)`, `available_at = avail_same_day_1800(d)`. `TPEX_TR` comes from FinMind `TaiwanStockTotalReturnIndex` with `data_id = "TPEx"` (column `price`) when `ctx.finmind` is available; otherwise skipped with a note.
