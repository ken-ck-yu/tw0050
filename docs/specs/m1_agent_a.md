# Agent A spec (M1): official daily files, market cap, snapshots, status events, universe

Builds on `docs/specs/m0_specs.md` (sections 2, 5, 7, 8, 15 apply) and the design. Two builders work in parallel on disjoint files: **A-1** (`daily_official.py`, `market_cap.py`, `snapshots.py`, `trading_calendar_derived.py`) and **A-2** (`status_events.py`, `stock_info.py`, `delistings.py`, `universe/classify.py`, `universe/build.py`). Each works in its own git worktree, only edits its own files under `src/twdata/ingest/` and `src/twdata/universe/`, its tests under `tests/agent_a/`, fixtures under `tests/fixtures/agent_a/`, a data dictionary file `docs/data_dictionary/a_<topic>.md`, and a run report `audit/runs/2026-11-14_agent_a_<1|2>.md` (template `audit/RUN_REPORT_TEMPLATE.md`; include what in the instructions was missing, ambiguous or wrong). No network access at any time: tests use the Lead's fixtures in `tests/fixtures/lead/` and a fake transport. Ingest modules expose `DATASETS: dict[str, Callable[[RunContext, date, date], None]]` and obtain clients, writers and the calendar from `RunContext` (`ctx.twse`, `ctx.tpex`, `ctx.finmind`, `ctx.writers(table)`, `ctx.calendar`, `ctx.cache`, `ctx.settings`). Client methods return `(records, response)`; `response.rows` are raw rows, `response.records` are dicts keyed by stripped field names (blank names `col<i>`, repeats `#2`), `response.fetched_at` is the raw response time. Use `fetched_at` of the response for each row. `available_at` rules come from `twdata.common.timeutil`. Resume with `twdata.common.state` (`is_done`, `mark_dates`, `mark_stocks`) and call `ctx.cache.flush()` after each batch.

## A-1

**`daily_official.py`** (`DATASETS = {"daily_official": run}`; also writes `shares_issued`). For each trading day `d` in `ctx.calendar` within `[start, end]` that is not done in state for `prices_raw` and `shares_issued`: fetch TWSE `mi_index(d)` (the per-stock table), TPEx `otc(d)` and TWSE `mi_qfiis(d)`. Use `twdata.clients.pair.fetch_daily_pair` for the `mi_index` and `otc` pair (it records a calendar discrepancy when both are empty on a trading day) and treat that day as non-trading for ingest. Batch rows for up to 20 trading days per `CleanWriter.append`, then `ctx.cache.flush()` and `state.mark_dates` for both datasets.
*   `prices_raw`, TWSE (fields of the `mi_index` per-stock table): `market="TWSE"`, `stock_id = 證券代號 stripped`, `stock_name = clean_name(證券名稱)`, `open/high/low/close = parse_number(開盤價/最高價/最低價/收盤價)` (null for `--`), `volume_shares = parse_int(成交股數)`, `turnover_ntd = parse_int(成交金額)`, `trades = parse_int(成交筆數)`. A no-trade row (prices `--`) is stored with null prices and zero volume, turnover and trades. `event_date = d`, `available_at = avail_same_day_1800(d)`. Call `sanity.check_price_row` on each row.
*   `prices_raw`, TPEx (`otc` fields, matched after whitespace stripping): `market="TPEx"`, `stock_id = 代號`, `stock_name = clean_name(名稱)`, `close = 收盤`, `open = 開盤`, `high = 最高`, `low = 最低`, `volume_shares = parse_int(成交股數)`, `turnover_ntd = parse_int(成交金額(元))`, `trades = parse_int(成交筆數)`. Cells use `----` for no trade (null prices, zero volume). The `漲跌` cell is not stored (use `parse_tpex_change` only if you validate it). Use `parse_number` for prices.
*   `shares_issued`: TWSE from `mi_qfiis`: `stock_id = 證券代號`, `isin = 國際證券編碼`, `shares_issued = parse_int(發行股數)`; TPEx from `otc`: `stock_id = 代號`, `isin = None`, `shares_issued = parse_int(發行股數)`. `available_at = avail_same_day_1800(d)`.
*   All rows of the daily files are stored (ETFs, receipts, warrants excluded by the endpoint's own `type`); classification happens in the universe step. Also register the view `listing_status` with `twdata.common.views.register_view`: per `(market, stock_id)` the first and last `event_date` in `prices_raw`.
*   Use the field names of the fixtures `tests/fixtures/lead/twse/mi_index_20160601.json`, `twse/mi_qfiis_20220601.json`, `tpex/otc_20160601.json`, `otc_20200601.json`, `otc_20250602.json`. A field list outside the registered eras is `drift` (the Lead registers the eras in `schema.py`; if they are missing, register them in your module through `schema.register_era` from the fixtures).

**`market_cap.py`** (`DATASETS = {"market_cap": run}`): for each `(stock_id, event_date)` where `default_prices_raw` has a non-null `close` and `default_shares_issued` has a row on the same date, write `market_cap` with `close`, `shares_issued`, `market_cap_ntd = close * shares_issued`, `available_at = avail_max(prices.available_at, shares.available_at)`, `fetched_at` = now (UTC). No carry-forward; a missing shares row means no market cap row (the universe counts these). Read the views through DuckDB (`views.register_views`) and Arrow; append per month.

**`snapshots.py`** (`DATASETS = {"snapshots": run_dataset}`; also `run(ctx)` for the CLI `snapshot` command): register one `schema.snapshot_table(name)` for each of the 15 endpoints in section 15.2 of the M0 specs at import time. `run(ctx)` first calls `import_stopgap(ctx)` (reads `data/raw/snapshots/manifest.jsonl` and the files it lists, idempotent, `fetched_at` parsed from the file stamp `YYYY-MM-DDTHHMMSS` as Asia/Taipei time), then fetches each endpoint live (`ctx.twse.openapi(path)` or `ctx.tpex.openapi(path)`). Rows: `snapshot_date` = the Taipei date of `fetched_at`, `first_seen_at = fetched_at`, `payload_sha256` = sha256 of the response body, `row_seq` = 0-based position in the payload, `row_json = json.dumps(row, ensure_ascii=False, sort_keys=True)`, `event_date = snapshot_date`, `available_at = first_seen_at`. A payload that is not a JSON list of objects writes nothing and raises `DriftError`. Empty list payloads write nothing but are recorded in state.

**`trading_calendar_derived.py`** (`DATASETS = {}`; function `diff(ctx, start, end) -> dict`): the dates with at least one `prices_raw` row compared with `ctx.calendar` days in the range, returning `{"finmind_only": [...], "derived_only": [...]}`, and writing it to `data/state/calendar_diff.json`.

## A-2

**`status_events.py`** (`DATASETS = {"status_events": run}`): `status_type` values `disposition` and `changed_trading`, `market` `TWSE`/`TPEx`. For each calendar year in `[start, end]`: TWSE `punish(start, end)` and TPEx `disposal(start, end)` → `disposition` rows; for each trading day TPEx `chtm(d)` → `changed_trading`.
*   TWSE `punish` fields (fixture `/tmp/claude-1000/-home-ken-tw0050/3508f076-53cf-4bb0-948d-cedb62426aaa/scratchpad/probe2/punish_2015.json`, copy a trimmed version into `tests/fixtures/agent_a/`): `公布日期` (ROC) → `announce_date`; `證券代號` → `stock_id`; `處置起迄時間` of the form `104/09/25～104/10/12` (full-width tilde) → `start_date`, `end_date`; `處置措施` → `detail`. Rows whose code does not match the common-stock rule are kept (filtering is the universe's job).
*   TPEx `disposal` fields (fixture `/tmp/claude-1000/-home-ken-tw0050/3508f076-53cf-4bb0-948d-cedb62426aaa/scratchpad/research/tpex/disp_2015.json`): `公布日期` → `announce_date`; `證券代號` → `stock_id`; `處置起訖時間` of the form `104/06/30~104/07/13` (ASCII tilde) → start and end; `處置原因` → `detail`.
*   For both, `event_date = announce_date`, `available_at = avail_next_day_0830(announce_date, ctx.calendar)`. A date range that fails to parse is `ParseError`.
*   TPEx `chtm` is a per-day state list. A row is a `changed_trading` day when any of `變更交易`, `分盤交易`, `屬管理股票` is non-empty (`Ｙ` full-width). Build events from runs of consecutive trading days for the same stock: `start_date` = first day seen, `end_date` = last day seen, `announce_date = None`, `event_date = start_date`, `available_at = avail_next_day_0830(start_date, ctx.calendar)`. A state already present on the first day of the requested range has `start_date` = that first day (record that limit in the dictionary). Resume across runs by re-reading the last event of each stock from `default_status_events`. The `停止交易` column is stored as `status_type = "halt"` rows only if you add `halt` to the registry in `schema.py` through a Lead request; otherwise ignore it and note it in the run report.

**`stock_info.py`, `delistings.py`** (`DATASETS = {"stock_info": run, "delistings": run}`, FinMind through `ctx.finmind.dataset(...)`): `TaiwanStockInfo` (columns `industry_category, stock_id, stock_name, type, date`) → `stock_info` (`event_date` = source `date`, no `available_at`), `TaiwanStockDelisting` (`date, stock_id, stock_name`) → `delistings`. If the primary key is not unique in a batch (`KeyUniquenessError`), write the offending keys to `docs/spikes/S6.md` and stop (spike S6).

**`universe/classify.py`**: `is_common_stock(stock_id: str, stock_name: str) -> bool`: `stock_id` matches `^[1-9][0-9]{3}$` and `clean_name(stock_name)` does not end with `-DR`. `normalise_name(name)` is `clean_name`.

**`universe/build.py`**: `rebuild(ctx, start, end)` and `DATASETS`-style entry `universe`. For each month-end (the last trading day of each month in `[start, end]`, from the calendar, starting 2015-06-30):
1.  Listed that day: `prices_raw` rows on that date. Common stocks by `is_common_stock`.
2.  Exclude stocks under a `disposition` or `changed_trading` event whose `[start_date, end_date]` covers the date (use `default_status_events`).
3.  Median turnover: the last 60 trading days up to and including the date; observed days are days with a `prices_raw` row whose `turnover_ntd > 0`; at least `settings.min_observed_days` observed days, and median `turnover_ntd >= settings.liquidity_floor_ntd`.
4.  Market cap on the date from `default_market_cap`. A missing market cap makes the stock ineligible and is counted per month in `data/state/universe_shortfall.json` (together with months with fewer than `universe_size` members).
5.  Rank by `market_cap_ntd` descending, ties by `median_turnover_60d` descending then `stock_id` ascending, keep the top `settings.universe_size`.
6.  Watchlist: rows from `config/watchlist.yaml` (each `{stock_id, start_date, reason, added_on}`) from their `start_date` onward, `is_watchlist = True`, `rank = None`. A stock already ranked keeps its rank and gets `is_watchlist = True`.
7.  Benchmark: 0050 gets a row every month with `is_benchmark = True`, `rank = None`, regardless of the filters.
Write `universe_membership` rows (`isin` from `default_shares_issued` or None, `market`, `market_cap_ntd`, `median_turnover_60d`, `available_at = avail_max(inputs' latest available_at)`) and rebuild `collection_set` (one row per stock: `first_month_end`, `last_month_end`, `ever_watchlist`, `is_benchmark`). Provide `assert_universe(rows)` that checks 200 ranked members per month-end (or the shortfall is recorded) and that 2330 is present each month, used by the M1 live gate. A change in a parser rebuilds into a new version (`CleanWriter(..., version=N+1)` then `set_current`).
