# Spike S6: TaiwanStockInfo key and date meaning (resolved 2026-11-14)

*   `TaiwanStockInfo` returns 4,389 rows for 3,182 stock ids. The key `(stock_id, date)` is **not** unique: a stock is listed once per `industry_category` (for example 2330 under more than one category on 2026-11-14), so the first load raised `KeyUniquenessError`.
*   Decision (Lead): key is `stock_id, event_date, industry_category` in `schema.py` (`event_date` is the source `date`). The loader normalises a null category to an empty string.
*   Open: what the source `date` means (change date or snapshot date) is still unverified. `stock_info` is a reference table and is not a feature input.
*   `TaiwanStockDelisting` loaded without a key problem.
